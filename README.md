# Memo Trip 🤖

A Telegram bot for planning dates, sharing ideas, and making decisions together.

## ✨ Features

- **Manage date ideas** — add, view, edit, and delete activities.
- **Voting system** — vote for ideas and check the results.
- **Matching choices** — find activities both participants like.
- **Random selection** — pick an idea when you cannot decide.
- **Budget-friendly dates** — discover affordable activities.
- **SQLite database** — persist data between bot restarts.
- **Interactive Telegram interface** — use commands and buttons to navigate.

## 🛠️ Tech Stack

- Python
- aiogram
- SQLite
- python-dotenv
- Linux server
- systemd

## 🚀 Deployment

Memo Trip runs as a background service on a Linux server.

Configuration and bot credentials are managed separately from the public source code.
